# Customs check for Dulor

Story mode shows Khuntau day the way we *think* it happens. Only horn oiling (with vermilion) and wall painting
were confirmed in written sources. Everything else is a best guess. Please go through this list and write next to
each line: **OK**, **wrong: ...** or **in my village: ...**. Short answers are fine. Claude will change the game to
match. Nothing here should be "fixed" by guessing.
